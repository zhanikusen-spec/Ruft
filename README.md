# Crust — сервер + игра

- `server.js` — HTTP + WebSocket сервер (комнаты `?room=1..4`, `?room=pvp1..4`)
- `index.html` — сама игра (адрес сервера подставляется автоматически, если игра открыта с этого же сервера)
- `render.yaml` — настройки для Render.com
- `package.json` — зависимости (`ws`)

## Запуск локально
```
npm install
npm start
```
Открой http://localhost:3000

## Деплой на Render
1. Залей папку в GitHub-репозиторий.
2. Render → New → Blueprint (или Web Service) → выбери репозиторий. Build: `npm install`, Start: `npm start`.
3. Открой выданный адрес `https://имя.onrender.com` — игра и мультиплеер работают с одного адреса.
4. Если игру хостишь отдельно, в игре впиши адрес вручную: `wss://имя.onrender.com`.

Бесплатный план Render засыпает без трафика — первое подключение может занять ~30–60 секунд.

Эндпоинты: `/health` (проверка), `/rooms` (онлайн по комнатам, JSON).

## Адрес сервера в игре
Серверы (4 в «Играть» и 4 арены PvP) вшиты в игру, вводить адрес не нужно.
- Игра открыта с самого сервера (`https://ИМЯ.onrender.com`) — адрес подставляется автоматически.
- Игра лежит отдельно — в начале `index.html` измени строку `window.CRUST_HOST='wss://crust-new.onrender.com'` на свой адрес.
